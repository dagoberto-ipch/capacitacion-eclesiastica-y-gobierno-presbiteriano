Que sirve en cada equipo

EquipoComo se instala
WindowsEdge o Chrome → menu → Instalar esta aplicacion
MacSafari → Archivo → Anadir al Dock
AndroidChrome → Anadir a pantalla de inicio
iPhoneSafari → Compartir → Anadir a pantalla de inicio

Un archivo APK no se puede instalar en iPhone, y una app de Mac o un IPA solo se compilan en un equipo con macOS. Por eso, para Mac e iPhone, la via es la aplicacion web instalable: un solo archivo sirve para los cuatro sistemas, pesa poco y ademas funciona sin internet.
